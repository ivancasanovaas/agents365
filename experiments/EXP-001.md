# EXP-001: smooth50 vs smooth50 with X (instead of D) on frames without ball

STATUS: defined, NOT executed. Never to be run on data/ from the agent side.

## Hypothesis
The organiser baseline labels frames without a visible ball as `D`. The ball is invisible on ~41% of
graded frames, so many in-possession frames become `D`, splitting possessions. Writing `X` there lets
the scorer forward-fill the previous label (spellF1) and should reduce fragmentation, at the cost of
macroF1 (an `X` on a graded frame is a miss).

## Variants (same nearest-player + centred majority vote, window +-50 frames)
- A: no-ball frames -> `D` (organiser baseline_smooth50 behaviour).
- B: no-ball frames -> `X`; the majority vote runs over frames with a label only; frames with no
  label in the whole window stay `X`.

## Evaluation
- Bench: external games (see external-validation), degraded with seeds 0..N-1, ball missing 41%.
- Metrics via `possession_metrics.evaluate`: primary spellF1 (headline + mean over IoU), secondary
  macroF1, plus fragmentation, number of possessions, `n_abstain_on_graded`.
- Decision rule fixed in advance: B is better only if the spellF1 gain across seeds exceeds the 0.04 noise band.
- Caveat to report: genuine dead balls inside the ball-missing set (labelled `D` in the GT) are
  lost by B; a dead-ball detector is the intended follow-up.

## Not allowed
Choosing A vs B using the 5-minute public GT.
