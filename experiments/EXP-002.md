# EXP-002: HMM/Viterbi versus the organiser smoothing baseline on the external bench (RETROSPECTIVE note)

STATUS: executed 2026-11-10/11 with `python -m src.external.run_exp002`. This file was written AFTERWARDS to make the early
choices traceable; it is not a pre-registration. The decision rule of this early experiment was informal (a visible gain over
smooth50 in cross-fitting and in transfer); every later experiment (EXP-003 onwards) has a rule written in advance.

## What was done
- External games: Metrica Sample Game 3 (cross-fitted by half) and SkillCorner 1874553 (transfer: parameters fitted on Metrica
  only). Degradation: the original bench (iid 0.3 m noise, ball gaps of 2 s), later recalibrated (EXP-008).
- Compared: organiser baseline smooth50 versus a 3-state HMM with naive-Bayes team evidence, with and without a ball-speed
  stream, and temperatures 0.5, 0.3 and 0.2 (`--temps`, default list of `run_exp002.py`).

## Results as recorded in the first version of the technical report (3 seeds; spellF1 / macroF1)
| setting | smooth50 | HMM (team evidence, temp 0.3) |
|---|---|---|
| Metrica, 2-fold cross-fit by half | 0.263 / 0.700 | 0.407 / 0.589 |
| Metrica -> SkillCorner (transfer) | 0.306 / 0.726 | 0.399 / 0.536 |

## Decisions that came from it
- `USE_SPEED = False`: the ball-speed stream helped within one game and did not transfer to the other.
- Temperature 0.3 was the best of {0.5, 0.3, 0.2} on these two settings. It was later reused (not retuned) for the softmax and
  re-checked in EXP-010/011 on 7 games (0.1, 0.5, 0.7, 1.0 all worse).
- Caveat recorded then and still valid: the temperature was chosen on the same games used to report, so those numbers were
  optimistic; the 7-game leave-one-game-out of EXP-010 is the first evaluation of the final recipe in which no game was used to
  train what it is scored on (the games were, however, all used in earlier decisions; see the technical report, section 4).
