# EXP-004: per-game quantile edges for the crowd-stillness stream

STATUS: executed 2026-11-12 on the external bench (3 seeds). Decision rule written before running.

## Motivation
The aggregate profile of the competition tracking shows a slower median player than Metrica (crowd-speed bucket shares
0.066/0.129/0.211/0.314/0.280 vs 0.040/0.101/0.174/0.283/0.401 on the calibrated bench). Fixed absolute edges could read
ordinary play as stillness and inflate D. Per-game quantile edges (quintiles of the game's own graded crowd speed) remove
overall tempo differences without labels.

## Rule (non-inferiority, fixed in advance)
Adopt quantile edges iff, in EVERY setting (Metrica 2-fold; Metrica -> SkillCorner; SkillCorner -> Metrica), mean spellF1
and macroF1 are each no more than 0.02 below the absolute-edge variant. The bench can only show that nothing is lost.

## Results (spellF1 / macroF1 / predicted D share; true D share in brackets)
| setting | C absolute | C quantile |
|---|---|---|
| Metrica 2-fold (0.301) | 0.445 / 0.708 / 0.304 | 0.428 / 0.714 / 0.328 |
| Metrica -> SkillCorner (0.457) | 0.441 / 0.783 / 0.406 | 0.394 / 0.776 / 0.492 |
| SkillCorner -> Metrica (0.301) | 0.432 / 0.729 / 0.345 | 0.441 / 0.716 / 0.300 |

Metrica -> SkillCorner: dSpell -0.047 -> INFERIOR. **Decision: KEEP absolute edges.**

### Re-run on bench v2 (2026-11-12, EXP-008 calibration with 16 s ball gaps), same rule
Metrica 2-fold dSpell -0.010 (non-inferior); Metrica -> SkillCorner dSpell **-0.049** (INFERIOR); SkillCorner -> Metrica
dSpell -0.005. **Decision unchanged: KEEP absolute edges.** (C absolute: 0.418 / 0.446 / 0.422; C quantile: 0.408 / 0.397 / 0.417.)
