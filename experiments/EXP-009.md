# EXP-009: possession duration handling (fewer one-second possessions)

STATUS: defined 2026-11-12 BEFORE running. Rule fixed. Bench v2 (EXP-008). Candidates compared DIRECTLY with the
production variant C (lesson of EXP-008).

## Motivation
On the competition match, 10% of our H/A runs last <= 1.8 s (p10), the median is ~6-7 s, and there are ~360 runs. spellF1
matches possessions one-to-one by temporal IoU, so spurious very short possessions are false positives and fragment real ones.

## Candidates (all on top of C = team + ball-outside + crowd stillness)
- `ha=0.5 / 0.25 / 0.1`: scale ONLY the H<->A transition probabilities by that factor (rows renormalised). Makes a direct team
  switch less likely; H<->D and D<->A are untouched. Value grid is coarse and fixed here; no other values are tried.
- `filter q=0.05 / q=0.10`: post-filter that removes alive (H/A) runs shorter than T, where T is the q-quantile of true
  possession durations in the TRAINING game(s) (external labels). Repeatedly, the shortest offending run (leftmost on ties) is absorbed
  by the LONGER neighbouring alive run, or relabelled D when neither neighbour is alive, until none is left. (Rule text
  refined before any run, after a unit test showed that a single left-to-right pass could leave a short run.) Origin of T: external labelled games, estimated by code, never the competition match.
Combinations are NOT tried in this experiment (a combination would be a new pre-registered experiment).

## Settings
Metrica 2-fold by half (T from the training half); Metrica -> SkillCorner; SkillCorner -> Metrica. 3 seeds, bench v2.

## Decision rule (per candidate, versus C measured in the same run)
Adopt iff in EVERY setting: mean spellF1 gain > 0.04, no seed regresses, D-F1 does not fall by more than 0.02 and macroF1 does
not fall by more than 0.02. If several candidates pass, the one with the highest mean spellF1 gain over the three settings is
adopted. If none passes, C stays and the result is recorded.

## Multiple-candidates note
Five candidates are tested against one baseline; requiring the gain in all three independent settings limits false passes.

## Not allowed
Choosing a candidate, a factor or a quantile by looking at the competition match, its public GT, or at which value wins after
the fact.

## Results (executed 2026-11-12, 3 seeds, bench v2)
Thresholds from external labels: q05 = 1.0-1.1 s, q10 = 1.0-1.5 s (the event/phase-derived external possessions include very
short ones, so the filter removes little). spellF1 gain over C (Metrica 2-fold / Metrica->SkillCorner / SkillCorner->Metrica):

| candidate | gains | verdict |
|---|---|---|
| ha 0.5 | +0.005 / +0.011 / +0.004 | fail |
| ha 0.25 | +0.002 / +0.021 / +0.009 (D-F1 -0.107 in the transfer) | fail |
| ha 0.1 | +0.003 / +0.026 / +0.010 (D-F1 -0.116 in the transfer) | fail |
| filter q05 | +0.006 / +0.008 / +0.004 | fail |
| filter q10 | +0.007 / +0.019 / +0.006 | fail |

**Decision: KEEP C.** All gains are positive but small (best +0.026), below the 0.04 noise band; stronger H<->A damping also
hurts D-F1 in the transfer. Fragmentation is not what limits spellF1 on the bench (C already predicts 389 segments vs 391
true in Metrica). The remaining error is which team holds the ball and when it changes, i.e. the evidence model itself.
