# EXP-013: non-linear emissions (one-hidden-layer MLP) vs the linear softmax

STATUS: defined 2026-11-12 BEFORE running. Rule fixed. Same protocol as EXP-010 (7 external games, leave-one-game-out, bench v2,
3 test seeds per game, temp 0.3, the 32 base features). Reference: production softmax.

## Why
The step from naive Bayes to a softmax gave +0.082 spellF1 because the signals are correlated and interact. A linear model
cannot represent interactions (e.g. "team-shape asymmetry matters when the ball is hidden but not when it is next to a player",
"crowd stillness means dead ball only if the ball is also slow or outside"). A small non-linear model can.

## Candidate
MLP: input 32 standardised features -> 32 ReLU units -> 3-way softmax; He-normal initialisation with a fixed seed; L2 1e-3 on the
weights; Adam, learning rate 0.02, 300 full-batch iterations; same training rows (every 5th graded frame plus the team-swapped
copy, 6 games per fold). All values fixed here; no tuning. Emissions are the scaled likelihood P(state | x) / P(state) with
temp 0.3, decoded with the same transitions as the softmax.

## Decision rule (MLP vs the linear softmax measured in the same run)
Adopt iff: mean spellF1 gain over the 7 held-out games > 0.04; gain > 0 in at least 5 of 7 games; mean D-F1 drop <= 0.02; mean
macroF1 drop <= 0.02.

## Not allowed
Changing the architecture or hyperparameters after seeing results (that is a new experiment); using the competition match, its
public GT or its output to choose among variants.

## Results (executed 2026-11-12, 7 games, 3 seeds, bench v2)
Mean over held-out games (spellF1 / macroF1 / D-F1): softmax 0.516/0.810/0.834 | mlp 0.543/0.822/0.844.
Per game spellF1 (softmax -> mlp): metrica_game3 0.502 -> 0.526, metrica_game1 0.475 -> 0.513, metrica_game2 0.495 -> 0.536,
skillcorner_1874553 0.552 -> 0.565, skillcorner_1886347 0.549 -> 0.583, skillcorner_1899585 0.523 -> 0.547,
skillcorner_1925299 0.516 -> 0.528.
MLP vs softmax: mean dSpell **+0.027, positive in 7/7**, dD-F1 +0.010, dMacro +0.012 -> below the 0.04 margin -> **fail**.
**Decision under the pre-registered rule: KEEP the linear softmax.**
Note for the report: the gain is consistent (7/7 games, sign-test p = 0.008) but modest; the 0.04 margin was chosen as the
scorer's single-match noise band and is conservative for a mean over 7 games x 3 seeds. Adopting the MLP would require a new
pre-registered confirmation on games never used in any decision (EXP-014 proposal: new SkillCorner matches as a untouched
hold-out set); it is NOT adopted by this experiment.
UPDATE: the proposed confirmation was run as EXP-014 on four untouched games and the MLP passed its pre-registered rule there
(higher in 3 of 4 games, mean +0.023); the MLP was adopted through EXP-014, not through this experiment.
