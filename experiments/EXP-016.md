# EXP-016: fresh cross-provider evaluation on the Sportec Open DFL games (native per-frame labels)

STATUS: defined 2026-11-12 BEFORE any DFL game was scored. No decision rule selects anything: this is a one-off evaluation that
also tells us how to use the DFL data afterwards. DFL games are loaded only through `src/external/dfl.py` and are NOT in
`registry.available()` until EXP-017 decides how to use them.

## Data
Seven Bundesliga matches (Sportec Open DFL Dataset, CC BY 4.0, figshare 28196177, 25 Hz). Each frame has a native `BallStatus`
(1 alive / 0 dead) and `BallPossession` (1 or 2). Label: D if the ball is dead, otherwise the team that owns it. This is the same
rule as the competition's ground truth is described to follow ("D where the corrected tracking marks the ball dead, otherwise the
team the tracking names as owning it"), with no event-to-label conversion. Graded frames: from the first to the last alive frame
of each half. First match inspected before writing this file (aggregates only): 41% D, 511 possession spells with a median of
3.0 s and a mean of 6.7 s, i.e. DFL possession flips are about twice as frequent as the competition's public ground truth (mean
14.2 s over 17 possessions). spellF1 on DFL is therefore not comparable with the earlier numbers and is expected to be lower.

## What is evaluated
The production artefacts exactly as committed (models/hmm_params.json, softmax_params.json, mlp_params.json), all trained on the 7
development games (event/phase-derived labels, none of the DFL games): A (team-only naive Bayes), C (+ ball-outside and stillness),
linear softmax, MLP. Each DFL game degraded with the calibrated bench (seeds 3000-3002), decoded with temp 0.3.

## Reported (not decisive)
Per game and mean: D-F1, alive/dead F1, team accuracy on frames that are H or A in the truth (strict), predicted D share vs true
D share, number of predicted possessions vs true possessions, spellF1 and macroF1 (spellF1 with the caveat above). A sensitivity
column re-scores spellF1 against DFL labels whose possession spells shorter than 3 s are merged into their longer neighbour
(`postfilter.min_duration_filter` with 3 s); the 3 s value is NOT tuned: it is the median DFL spell, reported only to show how
much of the spellF1 gap is label granularity.

## Why it matters
D-F1, alive/dead F1 and team accuracy have the same meaning here as in the competition, so they are the first comparison of our
models against labels with the competition's own definition, from a different provider and league.

## Not allowed
Choosing or retuning anything with these results in this experiment; changing the DFL label rule after seeing them (a different
use of the DFL games is a new pre-registered experiment, EXP-017).

## Results (executed 2026-11-12, 7 DFL matches, 3 seeds each)
Mean over the 7 matches (spellF1 / spellF1 vs 3 s-merged labels / macroF1 / D-F1 / alive-dead F1 / team accuracy):
- A: 0.228 / 0.306 / 0.595 / 0.633 / 0.724 / 0.600
- C: 0.292 / 0.389 / 0.720 / 0.854 / 0.888 / 0.670
- linear softmax: 0.336 / 0.474 / 0.749 / 0.819 / 0.846 / 0.700
- **MLP (production): 0.359 / 0.479 / 0.775 / 0.855 / 0.873 / 0.708**
The ranking A < C < softmax < MLP is the same as on the development games and the hold-out, now on a different provider and league with
native labels. MLP per match: D-F1 0.813-0.876, strict team accuracy 0.618-0.746, spellF1 0.320-0.398 (0.445-0.519 against 3 s-merged
labels). The models predict 0.42-0.59 dead ball against 0.41-0.52 true in 6 of 7 matches (over-prediction of 3-9 points) and about
half as many possessions as the DFL labels contain (e.g. 234 predicted vs 511 true), which is the label granularity noted above.
Nothing is selected by this experiment; it motivated EXP-017.
